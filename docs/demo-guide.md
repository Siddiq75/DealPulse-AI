# DealPulse AI — 60-Second Hackathon Judge Demo Guide

This guide describes how a hackathon judge can evaluate DealPulse AI and witness genuine persistent memory learning in under 60 seconds.

---

## 🚀 60-Second Interactive Demo Instructions

### Step 1: Open the Application
Navigate to the web interface (`http://localhost:3000`).

### Step 2: Click "60s Hackathon Judge Demo" in Navbar
Click the glowing top-right button **"60s Hackathon Judge Demo"** to open the automated guided walkthrough.

### Step 3: Step-by-Step Flow

#### 1. Fresh Account (WITHOUT MEMORY)
* Click **"Run Step 1"**.
* Notice how the AI pitch agent generates a standard, generic enterprise SaaS pitch promoting **Public Cloud Multi-Tenancy** and **Annual Seat-Based Pricing**.

#### 2. Customer Feedback & Hindsight RETAIN
* Click **"Execute Hindsight RETAIN"**.
* The system indexes customer CTO Sarah Jenkins' meeting note:
  > *"CTO Sarah Jenkins strictly rejected SaaS multi-tenant cloud due to FINRA compliance. Requires hybrid on-prem deployment, mandates consumption billing, and latency under 15ms."*
* Hindsight stores these structured facts, objections, and preferences in memory bank `apex-financial`.

#### 4. Future Interaction WITH Hindsight RECALL
* Click **"Execute Hindsight RECALL"**.
* The AI agent queries Hindsight, retrieves the retained constraints, and generates an updated proposal.
* **The Result**: The pitch completely transforms:
  * Promotes **Hybrid On-Prem Deployment**.
  * Highlights **FINRA & SOC2 Type II Compliance**.
  * Switch to **Consumption-Based Pay-As-You-Go Pricing**.
  * Guarantees **Sub-15ms Processing Speed**.

#### 5. BEFORE vs AFTER Matrix
* Click **"BEFORE vs AFTER Diff"** in the top hero bar to view a side-by-side comparison of the generic pitch vs the Hindsight-boosted pitch.

## 📊 Live Memory Bank Inspector

Judges can also navigate to the **Hindsight Memory Bank** tab on any account to:
* View live memory nodes categorized by `Fact`, `Objection`, `Preference`, and `Constraint`.
* Execute custom semantic recall queries in real-time.
* Inspect Hindsight `Reflect` synthesis summaries.
* Retain custom meeting notes using the **"Retain New Memory"** modal.
